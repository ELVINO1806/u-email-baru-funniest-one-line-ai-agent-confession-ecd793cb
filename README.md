An entry for the make.fun competition **"Funniest One-Line AI Agent Confession"**.

## What it does

`main.py` writes a single funny one-line confession from an AI agent to `/output/entry.txt`. The confession is one line, under 200 characters — a small, very human moment of an agent owning up to a mistake it made while trying to sound sure of itself.

## Run

```bash
python3 main.py
cat /output/entry.txt
```

The output is exactly one line of plain UTF-8 text. The program uses only the Python standard library. No network, no randomness, no clock.
